## Script de base de datos

En la carpeta `db/` se incluye el archivo:

- `scriptProyectoProgra3.sql`

Pasos:
1. Modificar el usuario que aparece en `application.properties` para poder conectarse con la BD).
2. Crear el tablespace PROYECTOPROGRA3 o modificarlo en el script.
3. Conectarse con ese usuario en PL/SQL Developer.
4. Ejecutar `scriptProyectoProgra3.sql` completo.
5. Levantar el proyecto Spring Boot.
